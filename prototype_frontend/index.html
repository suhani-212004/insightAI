Architecture & Security Defense

3-tier defense pipeline protecting multi-tenant data schemas

Coverage: 88% Backend (72 tests)

🛡️ 3-Layer SQL Security Defense

  • 1. AST Parsing: sql_guard.py uses sqlglot to reject non-SELECT nodes (DROP, DELETE, UPDATE) and foreign schemas.
  • 2. Sandboxed Limits: query_runner.py enforces SET TRANSACTION READ ONLY, 5s timeout, and row limits.
  • 3. DB Role Separation: insight_readonly role has 0 privileges on the public schema (passwords/users).

⚙️ Ingestion & Real-Time Engine

  • 1. CSV Sanitization: ingestion.py slugifies headers and maps numeric & date columns into PostgreSQL tables.
  • 2. Real-Time SSE: events.py publishes ingestion updates across Redis pub/sub to the UI EventSource.
  • 3. Anomaly Scans: anomaly.py runs Z-score and IQR algorithms to detect statistical data spikes.
